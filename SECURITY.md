# Security Policy

## Reporting a Vulnerability

`pytest-pubsub` depends on `google-api-core`, but if you find a security issue in this
project itself, please report it privately rather than opening a public GitHub issue:

- Preferred: open a [GitHub Security Advisory](https://github.com/rhasan33/pytest-pubsub/security/advisories/new) for this repository.
- Alternative: email the maintainer at rhasan.amiya@gmail.com.

Please include a description of the issue, steps to reproduce, and the
potential impact. We'll acknowledge reports as soon as possible and follow up
once a fix is available.

## Supported Versions

The project is currently pre-1.0 (`0.x`). Only the latest published release is
supported; please upgrade before reporting an issue that may already be fixed.
